Before you open the gates.

A free, open-source desktop toolkit for Twitch streamers. Bring your banners, your rules and your art.

Drill before you go live

Preview and simulate before acting on a live audience. Simulated results stay visibly labelled.

One verdict before everything

A barred message never counts toward a draw, a vote, a chant or a consensus.

Lots you can check

Seal the roll, announce a public round, derive the winners and publish the proof. Animation never chooses a winner.

Watching first

A Steward, if you want one

The AI co-pilot proposes a configuration change. Nothing changes until you seal it. Local processing is the default; cloud use is opt-in.

Chamber 1 of 4 · Lottery manager

Lot Chamber

Lottery manager

Seal the roll. Wait for a public round. Cast the lots.

Check releases ↗Full feature list →

  1. Seal. Freeze the entry list and publish its hash.

  2. Beacon. Announce a future public drand round, then verify its signature.

  3. Cast. Code derives the winners. The animation shows a result already decided.

  4. Writ. Download a proof bundle that anyone can recompute.

← Back to the Lot Chamber

Inside the Lot Chamber

A free entry path gets equal odds. Paid entry and paid weight are blocked by default for prize draws. Offline draws are labelled streamer-controlled. Prize rules and a Twitch disclaimer belong beside the draw.

Design overview. Check releases for current availability. Illustration and figures are simulated.

Chamber 2 of 4 · AI moderator

Gatehouse

AI moderator

One gate guards the room and reads it.

Check releases ↗Full feature list →

  1. Watching first. Shadow mode reports what a rule would do. It takes no action.

  2. Human review. Bans need a human click by default. Every action records its reason.

  3. The Herald’s chart. Opinion directions describe chat. The chart cannot act on a person.

  4. The drill. Replay recorded chat through proposed rules before using them live.

← Back to the Gatehouse

Inside the Gatehouse

Chat delay, held-message review and Shield Mode work beside deterministic rules. Room modes run on timed leases. Crisis disclosures reach a human. Replays stay labelled simulated and never write to the live decision ledger.

Design overview. Check releases for current availability. Illustration and figures are simulated.

Chamber 3 of 4 · Contribution visuals

Beacons

Contribution visuals

Money changes how it looks, never what it decides.

Check releases ↗Full feature list →

  1. Kindling curve. Map contributions to intensity ranges with a decay rule.

  2. Your own canvas. Camera frames, screen borders and objects share one renderer.

  3. Test fire. Preview a simulated 50-sub gift bomb before going live.

  4. On stream. Deliver the visual to OBS as a local browser source.

← Back to the Beacons

Inside the Beacons

Bits, subs, gifts, Hype Train, channel points, charity and goals feed intensity. Image, shape, text and particle layers bind to the blaze. Money never changes a draw, a vote, a rank or a moderation decision.

Design overview. Check releases for current availability. Illustration and figures are simulated.

Chamber 4 of 4 · Extension studio

Map Room

Extension studio

A studio for interactive designs, expressed as data.

Check releases ↗Full feature list →

  1. Templates. A hex map, a choice board, a viewer card, a draw and a contribution meter.

  2. Who drives. A human, an AI operator, or an AI that proposes for human approval.

  3. Test ladder. Local test, then Hosted Test for allowlisted accounts.

  4. Twitch review. Public Extension availability depends on Twitch policy approval and review.

← Back to the Map Room

Inside the Map Room

The planned shell bundles its code and reads design data. It loads no remote scripts and evaluates no generated code. Viewer content needs a Twitch ID, streamer approval and attribution. Bits never buy random outcomes. This page does not claim an approved Extension.
